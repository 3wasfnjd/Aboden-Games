# عبودين قيمز · ABODEN GAMES

موقع الاستديو الرسمي على https://abodengames.com، في مستودع `aboden-games1/aboden-games1.github.io`.

## التشغيل

Node.js 24، ثم `npm ci` و`npm run dev`. البناء: `npm run build`. فحص الروابط: `python3 scripts/verify-build.py`.

عدّل `src/` و`public/` فقط، ثم `node scripts/sync-pages.mjs` لنسخ البناء إلى جذر Pages. لا تحذف ملفات الألعاب أو السياسات. بيانات الموافقات الأصلية وملفات الألعاب وصورها محفوظة.

## المحتوى

- `src/data/catalog.json`: الألعاب الثمانية المعتمدة، دون تغيير المحتوى الأصلي.
- `src/data/game-sections.json`: فئات الألعاب وبيانات التحكم اللمسي المستندة إلى التعليمات الأصلية. دعم اللمس ليس شهادة توافق على كل جهاز.
- `src/data/studio.json`: بيانات الاستديو، البريد، الفريق، ورابط متجر دحروج Meta Quest. البريد فارغ حاليًا، لذا النماذج تجهّز الرسالة للنسخ أو التنزيل ولا تدّعي إرسالها. عند اعتماد البريد، تعبئة `contactEmail` و`supportEmail` تفعّل فتح تطبيق البريد بالمحتوى الجاهز.
- لإضافة عضو فريق، أضف `{ "name": "...", "role": "...", "bio": "..." }` إلى `team`.
- `public/privacy-policies/`: سياسات الألعاب المنشورة بالرابط المباشر، مستثناة من القوائم والبحث.
- `privacy-drafts/`: مسودات خارج البناء. المستودع عام، فلا تُخزّن معلومات سرية.
- `/dahrooj-privacy.html` محفوظ كما كان، ونسخة مطابقة في `/privacy-policies/dahrooj-meta-quest.html`.
- `migration/`: جرد ومجاميع SHA-256 للملفات الأصلية لضمان الحفاظ عليها.

## النشر

Pages من `main` والجذر، مع CNAME الأصلي و`.nojekyll`. سير العمل يختبر ثم يبني ويزامن دون حذف ملفات سابقة، ويطلب بناء Pages، ويتحقق من الصفحات والسياسة المنشورة. ملفات review القديمة للتشغيل اليدوي فقط؛ apply-dahrooj-poster القديم مقيد بمستودع المصدر ولا يعمل هنا.

التصميم عربي RTL بالأبيض والكحلي #0B1730، وشعار Cairo المعتمد، وخطوط محلية. يشمل البحث والتصفية، تجاوب الجوال، تنقل لوحة المفاتيح، تقليل الحركة، انتقال صفحات اختياري، بيانات مشاركة وأيقونات تطبيق. لا توجد تحليلات أو خدمات نماذج خارجية.

حالة الفهرسة بقيت `noindex, nofollow` امتثالًا لتعليمات المشروع السابقة حتى اعتماد الفهرسة. لم يتم تعديل مستودع المصدر أو أي مستودع لعبة.
